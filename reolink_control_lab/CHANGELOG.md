# Changelog

## 0.1.0

- Experimental companion UI and capability-gated Home Assistant MQTT entities.
- Read-only startup, manual refresh, command validation and per-device serialization.
- Optional camera webhooks, with existing webhook protection and graceful restoration.
- On-demand JPEG snapshots and recording metadata search.
- No firmware, credential or network changes; unimplemented audio/talk features are clearly identified.
