# Reolink Control Lab

Experimental companion to Reolink Stream Bridge. Provides an Ingress control panel, capability-gated MQTT discovery, on-demand snapshots and recording metadata search. Starts in read-only mode; camera event registration and disruptive commands are opt-in.

Keep your current video bridge. This app does not replace it or implement every protocol command. See DOCS.md for installation, supported features and limits.
